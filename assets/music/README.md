# assets/music

Canciones para la música de fondo. Al detectar el doble aplauso se elige **una
al azar** de esta carpeta (subcarpetas incluidas).

Los audios no se versionan (ver `.gitignore` en la raíz): son pesados y tienen
derechos de autor de terceros. Poné acá los tuyos.

Extensiones soportadas: `.mp3`, `.wav`, `.ogg`, `.oga`, `.flac`, `.m4a`, `.opus`.

Podés agregar, borrar o renombrar archivos libremente — la carpeta se escanea en
cada arranque. Lo único que depende del nombre es el filtro `include` del
`config.toml`, si lo usás.
